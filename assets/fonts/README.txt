Bundled webfonts (self-hosted)
==============================

These fonts are bundled with the Yesterday theme and served locally (no external
requests). All are licensed under the SIL Open Font License, Version 1.1 (OFL-1.1).

- Inter            — Copyright The Inter Project Authors (https://github.com/rsms/inter)
- Lora             — Copyright The Lora Project Authors (https://github.com/cyrealtype/Lora-Cyrillic)
- Playfair Display — Copyright The Playfair Display Project Authors (https://github.com/clauseggers/Playfair-Display)

Files are the "latin" subset in variable woff2 format, obtained from Google Fonts
(fonts.google.com). The OFL-1.1 license text applies to each; see
https://openfontlicense.org/ . A consolidated credits list is maintained in the
theme's readme.txt (Credits section).
